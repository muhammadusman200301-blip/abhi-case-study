**Abhi** is a payroll and salary-advance platform that companies use to pay and support their staff. It is used by 5,000+ companies.

|---|---|

## Tech stack
Node.js · TypeScript · PostgreSQL · REST APIs · AWS

## What I built
- Node.js and TypeScript **REST APIs** for transaction workflows
- **Request validation** and error handling so every transaction stays correct
- **SQL query tuning** and indexing on the slowest queries as usage grew
- Production support for transaction-related issues

## Challenges and how I handled them
- **Queries slowing down as data grew** – found the slowest PostgreSQL queries and added the right indexes.
- **Money has to be correct** – strict validation on every request and clear error handling so bad data never reaches a transaction.
